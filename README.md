# Django Learning Playground

A collection of beginner-friendly Django projects for practicing Python web development and learning Django concepts through hands-on examples.

## Projects

### 1. Employee Details

A Django employee directory for viewing employee records, including names, ages, joining dates, designations, and email addresses. The project also includes an employee detail page.

- **Project folder:** `EmployeeDetails/`
- **Django app:** `EmployeeDetailsApplication/`

### 2. ToDo List

A Django project for practicing how to display and work with tasks using Django views and templates.

- **Project folder:** `TodoProject/`
- **Django app:** `TodoApplication/`
